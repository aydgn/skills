# Bun Documentation

Use **live official Markdown**, not bundled snapshots or recalled API details.

1. Find the relevant page in [llms.txt](https://bun.sh/llms.txt). Use its document path under `https://bun.sh` and fetch only the needed `.md` pages (usually 1–3).
2. If the index lacks a topic, open its [documentation page](https://bun.sh/docs) and follow **View as Markdown**. If Markdown cannot be retrieved, read the equivalent `bun.sh` HTML page. Consult the [sitemap](https://bun.sh/sitemap.xml) only as a last resort; never load it in full.
3. Check exact commands, options, version requirements, and experimental limitations. Answer directly and link the **specific `bun.sh` pages** supporting the answer.
